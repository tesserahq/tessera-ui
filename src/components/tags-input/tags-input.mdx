# TagsInput

The `TagsInput` component lets a user build up a list of free-form string tags as pill-shaped chips. Type text and press Enter, comma, or Space to commit it as a tag (typing "hello there" produces two tags); Backspace on an empty input removes the last tag. Duplicate tags (after trim + lowercase normalization) are ignored.

## Usage

```tsx
import { TagsInput } from 'tessera-ui/components/tags-input'
import React from 'react'

const [tags, setTags] = React.useState<string[]>(['newsletter'])

<TagsInput value={tags} onChange={setTags} placeholder="Add a tag" />
```

# ComboBox

The `ComboBox` component is a flexible, searchable dropdown that works with string arrays or object arrays. It supports custom option rendering, search/filter, and integrates with forms via a hidden input. Use it for selecting a single value from a list with optional type-to-search.

## Usage

```tsx
import { ComboBox } from 'tessera-ui/components/combo-box'
import React from 'react'

const fruits = ['apple', 'banana', 'cherry', 'date', 'elderberry']
const [selected, setSelected] = React.useState<string | null>(fruits[0])

<ComboBox
  name="fruit"
  label="Select a fruit"
  value={selected ?? ''}
  onChange={(fruit) => setSelected(fruit)}
  options={fruits}
  getOptionId={(fruit) => fruit}
  getOptionLabel={(fruit) => fruit}
  placeholder="Search fruits..."
/>
```

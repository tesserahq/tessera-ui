# Pagination

The `Pagination` component renders a full pagination bar: "Items per page" size selector (25, 50, 75, 100), current range label (e.g. "1–25 of 120"), and first/prev/page numbers/next/last controls. It can drive the current page and size via URL (scoped params) or via an optional callback.

## Usage

```tsx
import { Pagination } from 'tessera-ui/components/pagination';
<Pagination
  meta={{
    page: 1,
    pages: 5,
    size: 25,
    total: 120,
  }}
/>
```

With a scope for URL-based navigation:

```tsx
<Pagination
  scope="list"
  meta={{
    page: 2,
    pages: 8,
    size: 25,
    total: 200,
  }}
/>
```

With a callback (no URL updates):

```tsx
<Pagination
  meta={{ page: 1, pages: 4, size: 50, total: 180 }}
  callback={({ page, size }) => {
    fetchPage(page, size)
  }}
/>
```

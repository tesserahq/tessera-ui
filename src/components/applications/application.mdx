# Applications

The `Applications` component renders an application launcher dropdown with a grid of app shortcuts. It reads application data and loading state from the app context and opens each app in a new tab.

## Features

- **Launcher trigger**: Opens from a compact icon button (`Grip`)
- **Context-driven data**: Uses `useApp()` for `applications` and `isLoadingApps`
- **Loading state**: Shows a spinner while app data is being fetched
- **Grid layout**: Displays applications in a 3-column responsive grid
- **Avatar fallback**: Uses the first letter when app logo is unavailable
- **External navigation**: Opens app links in a new browser tab

## Usage

```tsx
import { Applications } from 'tessera-ui'
import { TesseraProvider } from 'tessera-ui'

function HeaderActions() {
  return (
    <TesseraProvider identiesApiUrl={import.meta.env.VITE_IDENTIES_URL} token={token}>
      <Applications />
    </TesseraProvider>
  )
}
```

## Props

`Applications` does not accept direct props. It depends on values provided by `AppProvider` context.
